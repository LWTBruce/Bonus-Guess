Audio Assets
============

Background music in `music/` is downloaded from OpenGameArt and selected for clear redistribution terms. The game uses these MP3/WAV files first and falls back to generated WAV music only if an asset is missing.

UI sound effects in `sfx/` are downloaded from OpenGameArt's CC0 "UI Sound Effects" WAV pack. The game uses these files first and falls back to generated WAV sound effects only if an asset is missing.
