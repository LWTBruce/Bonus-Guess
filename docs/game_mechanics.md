# 游戏机制说明

本文档记录当前版本的核心玩法和参数。游戏内入口会先让玩家选择“快速上手”或“详细规则”，两者分别进入不同页面。

## 简单说明

《有（×）无奖竞猜》会从词库里抽取一个物理或数学专有名词。自由、限时、真·随机和自由段位玩法显示中文首字母；线索玩法不显示首字母，而是显示递进描述；自定义玩法允许自己配置词库和题目参数。玩家输入原来的中文专有名词，答对后结算用时、得分和 Rating。

普通和困难模式中，较长词条的首字母可能出现 `*` 掩码。例如“分析力学”的首字母是 `FXLX`，题面可能显示成 `FX*X`。掩码只遮住题面，不改变答案，也不改变“同首字母答案都算对”的规则。

同一个首字母可能对应多个词。只要答案在本局考察词库中，且首字母相同，就算答对。

如果答案不在本局词库里，但确实在当前大范围词库里，而且首字母相同，系统才提示“超纲啦，再想想~”。随便输入一个碰巧首字母相同的词不会被判成超纲。

玩法分七种：

| 玩法 | 规则 |
|---|---|
| 自由 | 单题练习，答对或失败后进入结算 |
| 线索 | 不显示首字母，显示答案字数，初始给一句描述，提示会逐步追加线索 |
| 限时 | 5 分钟连续答题，答对立刻换下一题，看最终答对题数和积分 |
| 真·随机 | 从物理和数学全部现有词库里抽题，只保留入门、简单、普通、困难四档选词难度 |
| 自定义 | 自选出题形式、词库、难度范围、词长、免费提示和掩码；限时与挑战题数是独立开关 |
| 自由段位 | 物理和数学分别有 15 个首字母限时挑战段位，通过后解锁段位标识和称号，并记录通过总分 |
| 线索段位 | 自由段位挑战的线索题版本，不显示首字母，进度和自由段位独立 |

每题从 1000 分开始，每过 1 秒扣 1 分。提示词库、付费字词提示和付费线索提示会额外扣分；开局免费字词提示不扣分，但每次使用字词提示后都会进入冷却。首字母题提示揭开全部汉字时，本题失败，记 0 分；线索题可以主动揭晓答案，揭晓后记为未答出，得 0 分。

每天同一个玩法、难度和词库范围下，会优先抽取当天还没有出现过的词。当天把这个范围里的词轮完一遍后，再从头开始新一轮。

最终总积分按来源加权：

| 来源 | 计入总积分权重 |
|---|---:|
| 入门 | 0.1 |
| 简单 | 0.2 |
| 普通 | 0.3 |
| 困难 | 0.4 |
| 混合模式 | 0.25 |
| 真·随机 | 0.25 |

自定义模式、自由段位和线索段位都会保存 record，方便回看。自定义记录不计入总积分、Rating、成就和常规统计；段位记录会保存单题原始分和本次挑战总分，用于段位结果页和段位选择页展示，但仍不进入常规统计、Rating 和成就。

## 详细规则

### 1. 题目范围

物理和数学词库统一放在 `words` 文件夹下，各有入门、简单、普通、困难、混合模式。入门偏高中基础词，简单到困难逐步进入大学基础和更高阶内容。混合模式读取当前学科下全部词库。后端的词库生成、难度补全和 CSV 修复脚本也默认只处理 `words` 下的 CSV。

真·随机不再区分物理和数学，而是把现有全部词库合在一起抽题。真·随机下没有“混合模式”按钮，四个难度只表示选词难度倾向。

限时模式固定 5 分钟。答对一题后立刻换下一题，每道完成的题都会写入 record；时间结束后显示本轮答对题数和计入总积分。

线索模式和自由模式并列，也有入门、简单、普通、困难、混合模式五档选词难度。线索模式不显示题目首字母，但会显示答案字数；初始显示第一句，最多共有五句线索，每按一次“提示”多显示下一句。玩家也可以点击“揭晓答案”，确认后本题记为未答出。

自定义模式是练习沙盒。可以选择物理、数学或全部词库，也可以在 `words` 下多选具体 CSV；出题形式保留首字母和线索两种；可以过滤基础难度 `1-10`、中文词长范围，设置免费字词提示为自动或固定值，设置掩码数量为自动或 `0-3`，并设置线索破碎概率为 `0%`、`25%`、`40%` 或 `100%`。固定免费提示会自动夹在 `0..词长-1`，避免开局直接揭完答案。

自定义页另有两个独立开关：限时和段位模式。限时可设 `1-30` 分钟；段位模式是自定义练习挑战，可设挑战题数，建议 `1-50`，默认 `5`。四种组合分别是：不限时且不开启段位模式为单题练习；限时且不开启段位模式为限时连续练习，看答对题数；不限时且开启段位模式为指定题数挑战；限时且开启段位模式为在时限内完成指定题数挑战。

自定义挑战要求连续完成指定题数才显示挑战成功。普通错误提交不会直接失败，可以继续作答；主动揭晓答案、提示揭完、中途退出或限时结束会显示挑战失败。自定义模式保存记录，但记录会标记 `custom_mode` 和 `exclude_from_stats`，并保持 `score_weight=0`，不进入总积分、Rating、成就、常规统计和正式段位奖励。

自由段位挑战分物理和数学两套进度。自由段位是一组限时首字母题，普通错误提交不会立刻失败，可以继续输入；但时间到、主动揭晓、提示揭完或中途退出都会导致本次挑战失败。全题最终答对且未超时才算通过，通过后写入 `record/rank_progress.json`，并解锁对应段位徽章和称号。自由段位题也会保存单题 record，并累计本次挑战总分；通过后段位选择页会显示该段历史最高通过总分。段位记录会标记 `rank_mode` 和 `exclude_from_stats`，单题原始分和挑战总分只用于段位展示，不进入常规统计、Rating 和成就。旧 record 中的 `段位` 会兼容展示为 `自由段位`。

线索段位使用同一张段位表，但全部题目换成线索题：不显示首字母，只显示答案字数和递进线索；普通错误提交仍可继续作答，主动揭晓答案、时间到、中途退出或作弊会导致挑战失败。线索段位和自由段位分别记录进度、徽章和称号，例如物理 `Class 05: Orbit` 与物理线索 `Class 05: Orbit` 是两个独立奖励。

段位提示规则独立于普通玩法：每一题开局时提示按钮处于完整冷却；1-5 段最多使用 3 次提示，6-10 段最多 2 次，11-15 段最多 1 次。段位冷却从 60 秒到 120 秒随段位线性增加。自由段位的掩码数量沿用普通/困难自由模式规则，不再为了凑目标难度额外提高掩码密度。

### 2. 词条难度概率

每个词条有 1-10 的基础难度值。抽题不是均匀抽取，而是先按当前选词难度抽一个难度层级，再在该层级内随机抽词。

| 模式 | 难度1 | 难度2 | 难度3 | 难度4 | 难度5 | 难度6 | 难度7 | 难度8 | 难度9 | 难度10 |
|---|---:|---:|---:|---:|---:|---:|---:|---:|---:|---:|
| 入门 | 33.98% | 35.98% | 17.99% | 7.00% | 3.00% | 1.00% | 0.60% | 0.30% | 0.10% | 0.05% |
| 简单 | 5.00% | 12.00% | 30.00% | 30.00% | 13.00% | 6.00% | 2.50% | 1.00% | 0.40% | 0.10% |
| 普通 | 1.00% | 2.50% | 7.00% | 14.00% | 28.00% | 27.00% | 13.00% | 5.50% | 1.50% | 0.50% |
| 困难 | 0.20% | 0.50% | 1.00% | 2.50% | 5.00% | 9.00% | 16.00% | 27.00% | 23.00% | 15.80% |
| 混合模式 | 10.00% | 10.00% | 10.00% | 10.00% | 10.00% | 10.00% | 10.00% | 10.00% | 10.00% | 10.00% |

真·随机使用玩家选择的入门、简单、普通、困难四档概率，但计入总积分时统一按 0.25 权重计算。

### 3. 首字母掩码与线索破碎

掩码只在普通和困难两档中出现。设首字母串长度为 L：

| 模式 | L=4 | L=5 | L>=6 |
|---|---|---|---|
| 普通 | 30% 掩 1 个 | 20% 掩 1 个，10% 掩 2 个 | 15% 掩 1 个，10% 掩 2 个，5% 掩 3 个 |
| 困难 | 45% 掩 1 个 | 30% 掩 1 个，20% 掩 2 个 | 25% 掩 1 个，20% 掩 2 个，15% 掩 3 个 |

其余概率为不掩码。掩码位置在首字母串内随机选择，且不会重复。

本题总难度按下面公式显示和记录：

```text
首字母题总难度 = 词条基础难度 + 0.5 * 掩码字符数
```

本题总难度会参与提示扣分、Rating 和成就判断；基础难度仍保留在 record 中，方便区分原词本身的难度。

线索模式有五条完整线索和五条对应破碎线索，并且线索文件按原词库目录分级保存，例如源词库 `words/物理/简单模式：普通物理/mechanics_terms.csv` 对应 `clues/物理/简单模式：普通物理/mechanics_terms.json`。五条完整线索按“应用场景、概念类型、具体运用、关键关系、近乎点明的关键词”递进；第一条不再使用“属于某方向”这种空泛提示，第三条不使用英文拆词，而改为说明更具体的用法或题目中如何出现。普通模式中每条线索有 25% 概率替换为破碎线索，困难模式中概率为 40%；每出现一条破碎线索，本题总难度增加 0.5。

```text
线索题总难度 = 词条基础难度 + 0.5 * 破碎线索数
```

### 4. 免费提示次数 m

设答案中文名有 n 个汉字。每题开局会随机生成免费字词提示次数 m：

```text
0 <= m <= floor(n / 2)
```

当 n=1 时，只能 m=0。当 n>=2 时，m=0 的概率随模式变难依次上调 5%。

| 模式 | P(m=0) | 衰减参数 d |
|---|---:|---:|
| 入门 | 50% | 0.78 |
| 简单 | 55% | 0.55 |
| 普通 | 60% | 0.38 |
| 困难 | 65% | 0.25 |
| 混合模式 | 60% | 0.45 |

剩余概率分给 m=1 到 floor(n/2)，并按指数衰减：

```text
P(m=k) = (1 - P(m=0)) * d^(k-1) / sum(d^(j-1), j=1..floor(n/2))
```

### 5. 提示扣分与冷却

每题初始 1000 分，时间扣分为每秒 1 分。

题目总难度越高，提示扣分越少一些，但提示代价仍然显著高于等待几秒。

```text
难度扣分系数 = 1.18 - 0.045 * 本题总难度
提示词库扣分 = max(90, round(210 * 难度扣分系数))
```

免费提示次数用完后，字词提示按下式扣分：

```text
基础值 = max(100, round(520 / 答案字数)) + 55 * (第几次字词提示 - 1)
字词提示扣分 = max(65, round(基础值 * 难度扣分系数))
```

每一题开局时提示按钮会先进入完整冷却；每次使用字词提示或线索提示后，提示按钮也会变暗，并直接显示剩余冷却秒数，例如 `45`、`44`、`43`。普通玩法和自定义玩法的冷却时间随选词难度增加：

| 模式 | 字词提示冷却 |
|---|---:|
| 入门 | 30 秒 |
| 简单 | 45 秒 |
| 普通 | 60 秒 |
| 困难 | 75 秒 |
| 混合模式 | 60 秒 |

提示词库按钮不受这个冷却影响。段位玩法使用段位表中的独立冷却和次数限制。

线索模式初始第一条线索直接显示；额外线索提示同样需要等待冷却。第一次按“提示”会揭露第二条线索且不扣分。从揭露第三条线索开始，按选词难度和本题总难度扣分：

```text
揭露第二条线索：0 分
揭露第三条及以后：模式基础值 + 18 * (本题总难度 - 1) + 70 * (付费线索提示序号 - 1)
```

模式基础值为：入门 120、简单 170、普通 240、困难 330、混合模式 230。揭露第三条线索是第 1 次付费线索提示，揭露第四条是第 2 次付费线索提示，揭露第五条是第 3 次付费线索提示。

### 6. Rating

Rating 用来衡量长期实力，最大值约 20，显示三位小数。它类似音游中的 B20 思路：难度是主要贡献，速度、提示和错误提交只做微调。

单局常数：

```text
C = clamp(0.5 + 1.62 * 本题总难度 + 选词难度补正 + 玩法补正, 0.5, 20)
```

| 选词难度 | 补正 |
|---|---:|
| 入门 | -0.7 |
| 简单 | 0.0 |
| 普通 | 1.0 |
| 困难 | 3.3 |
| 混合模式 | 1.0 |

| 玩法 | 补正 |
|---|---:|
| 自由 | 0.0 |
| 限时 | 0.25 |
| 线索 | 0.20 |
| 真·随机 | 0.40 |

表现质量 Q 综合原始得分、速度、提示和错误次数。失败题单局 Rating 为 0。

```text
期望用时 T = 8 + 2.4 * 答案字数 + 1.6 * 本题总难度
Rating = clamp(C * ((Q - 0.55) / 0.45)^2, 0, 20)
```

总 Rating 由历史最佳不同词条记录、近期记录和成就完成数量共同决定：

```text
作答Rating = 0.85 * B20均值 + 0.15 * R10均值
总Rating = clamp(作答Rating + 成就奖励, 0, 20)
```

同一个“模式 + 答案”只保留历史最高单局 Rating，避免反复刷简单词条把 Rating 水高。

成就奖励只占较小部分，按完成成就数和完成比例缓慢增长，上限约为 `2.15`。这样长期探索、解锁不同玩法和高难目标会推高 Rating，但主要贡献仍来自真正答题表现。

Rating 还会解锁可佩戴称号和头像。门槛先稀疏后密集：`0`、`5`、`8`、`10`、`12`、`14`、`15`、`16`、`17`、`17.5`、`18`、`18.5`、`19`、`19.5`、`20`。部分成就也会额外解锁称号；设置页只显示当前已经解锁的可佩戴项。

### 7. 记录、统计与成就

每条 record 会保存题目、显示首字母或线索题标记、原始首字母、掩码位置、线索内容、破碎线索数量、基础难度、总难度、答案、可接受答案、学科、玩法、选词难度、所有提交、是否成功、是否主动揭晓、用时、提示次数、扣分细节、原始得分和计入总积分。记录文件按月份和日期分层保存，例如 `record/2026-05/2026-05-21/20260521_120426_xxxxxxxx.json`。

自定义记录会额外保存 `custom_config`、`custom_files`、`custom_play_kind`、`custom_timed_enabled`、`custom_challenge_enabled`、`custom_challenge_target`、`custom_challenge_progress` 和本次自定义 session；段位记录会额外保存 `rank_subject`、`rank_kind`、`rank_progress_key`、`rank_id`、`rank_question_index`、`rank_target_difficulty`、`rank_relaxed`、`rank_session_score`、`rank_hint_used`、`rank_hint_limit` 和本次挑战 session。二者都保留在历史列表里，但统计汇总、Rating 和成就会跳过它们。

每日抽题轮转状态单独保存在 `profile/daily_terms.json`。它只记录当天每个范围已经推送过哪些词，不参与得分；日期变化后会自动清空。

段位进度单独保存在 `record/rank_progress.json`。这个文件记录物理和数学各自的最高通过段位、每段首次/最近通过时间，以及通过时的最高总分，不会被当作游玩记录读取。

中途返回或关闭窗口会记录为 abandoned。它不算做题，不算答错，但会计入退出次数和退出类成就。

历史记录页会统计总做题数、总用时、总积分、Rating、字词/线索提示数，并能在“详情”里按学科、玩法和选词难度分别查看题数、答对数、积分和退出次数。

成就系统包含启动、答对、提示、掩码题、线索总难度、限时模式、累计时长和大量长期目标。成就页会按通用入门、自由与常规、线索与高难、提示与词库、掩码首字母、限时模式、长期积累、系统与退出等类别展示，每类内部大致从容易到困难排列。少量可从标题揣摩的隐藏成就会集中放入“神秘成就”，未完成时只显示“？？？”，达成后才显示真实条件。

### 8. 视觉设置

设置页可以调整背景粒子速度、背景粒子密度，范围为 0.4 倍到 10 倍，也可以关闭页面过场动画。页面过场动画会在切换大页面时随机使用幕帘、开窗、条带、扫描线或斜切等短动画，单次持续时间小于 1 秒。

答对、失败和限时模式自动换下一题属于即时反馈，不播放页面过场动画，避免打断答题节奏。

设置页还可以佩戴已解锁头像、称号和段位标识；未解锁段位标识时会提示“通过自由段位或线索段位后解锁”。段位标识采用像素边框徽章样式，1-15 段从黑、灰、红橙黄绿蓝紫、白色逐步过渡到更鲜艳的彩色标识，会在主页玩家卡片中和昵称、称号、Rating 一起显示。
