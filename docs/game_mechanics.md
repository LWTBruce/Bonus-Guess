# 游戏规则

本文对应 `0.3.2` 的玩家可见规则。它解释你在游戏里会看到什么、怎样作答、提示会怎样影响分数，以及记录和称号如何保存。

## 简单说明

《有（×）无奖竞猜》会从物理或数学词库里抽取一个中文专有名词。你根据首字母、线索或字谜网格输入完整中文名。

常用入口：

| 入口 | 适合做什么 |
|---|---|
| 自由 | 单题练习，答完一题就结算 |
| 限时 | 5 分钟内连续答题 |
| 线索 | 根据逐步展开的描述猜词 |
| 字谜 | 在交叉网格里填写多个词 |
| 段位挑战 | 完成固定难度目标，获得段位标识 |
| 真·随机 | 从更大的跨学科词库里抽题 |

难度顺序是：

```text
入门 -> 简单 -> 普通 -> 困难 -> 噩梦
```

普通及以上难度可能出现 `*` 掩码。`*` 代表这里不限制首字母，答案仍然要输入完整中文名。噩梦模式是困难模式之后的自然延伸：词更偏前沿和专门方向，掩码更多，提示更少，字谜棋盘也更大。线索玩法暂时不开放噩梦词库。

如果题目含有人名、英文字母或希腊字母，作答区会直接标注，例如“本题含有人名、希腊字母”。字谜模式会在每个词条右侧标注同样的信息。

人名按大陆常见译法作为默认写法。部分人名存在多种音译，输入可接受别译也会算对；字谜模式会把网格填成词库里的默认写法。

提示和词库提示都能帮你缩小范围。教程题会免费让你体验一次，但正式局中过多使用提示会扣分；揭晓答案或把提示全部用完通常会让本题失败。

## 详细规则

### 词库与难度

词库位于 `words/`，按学科和难度分组。物理和数学都有入门、简单、普通、困难词库；自由、限时和字谜玩法还可以使用噩梦词库。

每个词条都有基础难度。抽题时会综合词条难度、词长和当前模式决定出现概率。更高难度会更常抽到专业、抽象或不容易凭首字母想到的词。

`混合模式` 读取当前学科的多个难度文件。`真·随机` 读取物理和数学的大范围词库，并按中文答案去重。

### 作答规则

自由、限时和普通随机题显示中文首字母。你需要输入完整中文名。答案满足以下条件时视为正确：

- 中文名与标准答案一致。
- 标准中文名里天然带 `-`、`－`、`–` 等连接符时，输入时省略连接符也算对。
- 含有人名的词允许输入人名别译，例如默认译名和常见音译都可接受。
- 首字母里有 `*` 时，`*` 位置不检查，其他位置仍需匹配。

如果输入的词存在于当前大词库但不在本局抽题范围内，系统会提示它是超纲词，不会直接算对。

### 人名、字母和希腊字母

人名译名表放在 `words/人名/人名译名表.md`。词库采用默认译名；别译只用于判题兼容。

含有人名、英文字母或希腊字母的题目会在作答页标注。希腊字母不会被忽略，首字母提示会显示对应的大写希腊字母，例如 `σ代数` 的首字母是 `ΣDS`。

字谜中如果你用别译答对，而别译与默认译名在交叉格上不同，系统会提示“作答正确，但是填入默认翻译”，并把网格填成默认译名。

### 提示

每题可能有若干免费字词提示。免费次数用完后继续使用提示会扣分。提示会揭开答案中的一个汉字；如果提示把答案全部揭开，本题会失败。

词库提示会告诉你当前词来自哪个范围或文件。它不受字词提示冷却影响，但正式局中同样会扣分。

线索玩法的提示会展开更多描述。第一条额外线索免费，之后会按题目难度扣分。

教程题会免费提供一次字词提示和一次词库提示，用来熟悉按钮位置和规则，不计入正式 Rating、成就或总积分。

### 限时

限时模式固定 5 分钟。答对一题后立即进入下一题；每道完成题都会保存记录。时间结束后显示答对题数、原始得分和计入总积分的分数。

限时题使用与自由模式相同的答案、提示和掩码规则。

### 线索

线索模式不显示首字母，只显示答案长度和逐步展开的线索。初始显示第一条线索，最多五条。部分高难线索可能较模糊，题目总难度会随之上升。

当前线索玩法开放入门、简单、普通、困难和混合模式；噩梦词库暂不进入线索范围。

### 字谜

字谜模式会把多个词放进同一张交叉网格。左侧按编号输入答案，右侧显示棋盘。答对一个词后，对应汉字会填入网格。

字谜同样支持省略自然连接符，也支持人名别译。若输入别译，网格仍使用词库默认译名。

棋盘会随难度变大。噩梦字谜比困难字谜更大、更偏高难词，并沿用更强的掩码规则。

字谜中的“提示”会揭开一个未确定格子；“提示词库”会提示某个未解词的来源范围。免费次数用完后继续使用会扣分。

### 计分与 Rating

单题基础分从 1000 分开始，时间、付费提示、词库提示和揭晓答案都会影响原始得分。字谜按整张图的词量和难度结算。

总积分按选词难度加权。入门权重最低，噩梦权重最高。自定义模式和教程题不计入总积分、Rating 或常规统计。

Rating 衡量长期表现，主要看题目难度、作答速度、提示使用和是否成功。重复刷同一类题不会无限抬高 Rating，系统会保留更有代表性的历史表现。

### 段位

段位挑战分为物理和数学，并按玩法拆分为限时、线索和字谜。通过某一段只解锁该段，不会自动补齐低段。

通过段位后会获得对应段位标识，例如 `物理-限时`、`数学-字谜`。你可以在设置页选择是否佩戴。

### 记录、称号与设置

每个账号都有独立的 record、成就、段位进度和设置。记录会保存题目、答案、模式、难度、用时、提示使用、得分和结算结果。

称号来自 Rating、通用入门、不同玩法、段位挑战和成就。设置页可以搜索、筛选并选择已解锁称号，也可以修改密码、切换账号、退出登录或重温新手教程。

账号数据按玩家独立保存；切换账号后会读取对应玩家自己的记录和设置。
