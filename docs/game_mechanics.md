# 游戏机制说明

本文档对应 `0.3.0` 规则。游戏内“快速上手”只讲操作；这里记录完整机制、参数和统计口径。

## 快速概览

《有（x）无奖竞猜》会从物理或数学词库中抽取一个专有名词，玩家根据首字母、线索或字谜网格输入原中文名。账号、记录、成就、段位和设置按玩家独立保存。

主流程分为四类：

| 大类 | 玩法 | 说明 |
|---|---|---|
| 普通 | 自由、限时、线索、字谜 | 使用当前学科词库。自由是单题练习，限时是 5 分钟连答，线索用递进描述，字谜生成交叉网格 |
| 随机 | 自由、限时、线索、字谜 | 跨物理和数学读取同一难度词库；“真·随机”读取全部词库 |
| 段位 | 限时、线索、字谜 | 物理和数学分别有 15 段正式挑战，进度和段位标识独立 |
| 自定义 | 自定义 | 自选词库、难度、限时、掩码、线索、字谜尺寸和仿段位目标 |

难度序列现在是：

```text
入门 -> 简单 -> 普通 -> 困难 -> 噩梦
```

`混合模式` 不是更高难度，而是读取当前学科的全部难度文件。`真·随机` 读取物理和数学全部词库并按中文答案去重；线索玩法中的混合模式和真·随机会排除暂未配套线索的噩梦词库。

噩梦模式是困难后的自然延伸，当前开放在自由、限时和字谜中；线索模式暂不开放噩梦，因为新噩梦词库还没有完整线索文件。噩梦的抽题更偏 10 级词，首字母掩码更密，免费提示更少，提示冷却更长，字谜棋盘也更大。

## 词库范围

词库统一放在 `words` 文件夹：

| 学科 | 目录 |
|---|---|
| 物理 | `words/物理` |
| 数学 | `words/数学` |

加载规则按目录名前缀匹配难度。例如选择“物理 / 普通”时读取 `words/物理` 下所有以 `普通` 开头的文件夹；选择“物理 / 噩梦”时读取所有以 `噩梦` 开头的文件夹。

0.3.0 新增词库包括：

| 学科 | 难度 | 新增方向 |
|---|---|---|
| 物理 | 普通 | 连续介质力学 |
| 物理 | 困难 | 宇宙学、量子信息 |
| 物理 | 噩梦 | 超弦理论与 M 理论、圈量子引力、共形场论、全息原理、拓扑量子场论、非对易几何、量子引力与黑洞信息悖论、进阶 QCD |
| 数学 | 简单 | 解析几何、初等数论、组合基础 |
| 数学 | 普通 | 变分法、积分方程、向量张量分析、运筹学 |
| 数学 | 困难 | 微分几何、代数几何、李群李代数、同调代数 |
| 数学 | 噩梦 | 算子代数、非交换几何、进阶表示论、模空间理论、算术几何、几何分析、随机矩阵理论、谱几何、导范畴、数学量子群 |

同一次加载会按 `(中文名, 首字母)` 去重。随机和真·随机跨学科加载后，还会按中文答案再次去重，避免同一个词因为存在于多个词表而获得更高抽取权重。

## 玩法规则

### 自由

自由模式显示中文首字母，玩家输入完整中文名。只要答案在本局词库范围内，并且首字母相同，就算答对。普通、困难和噩梦可能出现 `*` 掩码；`*` 处不限，只检查未掩码位置。

如果输入词不在本局范围内，但确实存在于当前大范围词库且首字母相同，系统会提示“超纲啦，再想想~”。随便输入一个碰巧首字母相同的词不会被判成超纲。

答对后立即结算。主动揭晓答案、提示揭开全部汉字或中途返回会让本题失败或放弃。

### 限时

限时模式固定 5 分钟。答对一题后立即换下一题，每道已完成题都会保存 record。时间结束后显示答对题数、原始积分和计入总积分。

限时使用与自由模式相同的抽词、掩码、提示和扣分规则。

### 线索

线索模式不显示首字母，只显示答案字数和递进线索。初始显示第一句，最多五句；每次提示多显示一句。普通模式中每条线索有 25% 概率替换为破碎线索，困难模式为 40%。每出现一条破碎线索，本题总难度 +0.5。

线索模式当前开放入门、简单、普通、困难和混合模式，暂不开放噩梦。线索的混合模式和真·随机也会过滤噩梦词库。

### 字谜

字谜模式把多个词放进同一张交叉网格。右侧是棋盘，左侧按编号输入答案；答对一个词后，对应汉字会填入网格。

字谜边长按难度增长：

| 难度 | 约边长 |
|---|---:|
| 入门 | 8 |
| 简单 | 11 |
| 普通 | 15 |
| 困难 | 18 |
| 噩梦 | 22 |

目标词量约为边长的 `1.8` 倍。生成器会多轮尝试布局，奖励交叉、覆盖和接近目标词量，惩罚过密填充、孤立词、空行空列和过多纵向单列词，并禁止同一张图里重复中文答案。

普通、困难和噩梦字谜会沿用同难度自由模式的掩码表，并把每种掩码数的权重额外提高。噩梦字谜的长首字母词几乎一定会被掩码，并且棋盘更大、词条更偏 10 级。

普通字谜有 15% 概率使用三角格、15% 概率使用六边格；困难分别提高到 20%；噩梦为 25% 三角格、30% 六边格。其余情况使用方格。大图支持滚轮缩放和拖动。

## 抽题概率

每个词条有 1-10 的基础难度。抽题时先按当前选词难度给基础难度赋权，再叠加词长权重。1 字和 2 字词会被降权，3 字及以上词会适度增权。

| 模式 | 难度1 | 难度2 | 难度3 | 难度4 | 难度5 | 难度6 | 难度7 | 难度8 | 难度9 | 难度10 |
|---|---:|---:|---:|---:|---:|---:|---:|---:|---:|---:|
| 入门 | 33.98% | 35.98% | 17.99% | 7.00% | 3.00% | 1.00% | 0.60% | 0.30% | 0.10% | 0.05% |
| 简单 | 5.00% | 12.00% | 30.00% | 30.00% | 13.00% | 6.00% | 2.50% | 1.00% | 0.40% | 0.10% |
| 普通 | 1.00% | 2.50% | 7.00% | 14.00% | 28.00% | 27.00% | 13.00% | 5.50% | 1.50% | 0.50% |
| 困难 | 0.20% | 0.50% | 1.00% | 2.50% | 5.00% | 9.00% | 16.00% | 27.00% | 23.00% | 15.80% |
| 噩梦 | 0.05% | 0.10% | 0.20% | 0.50% | 1.00% | 2.00% | 5.00% | 14.00% | 27.00% | 50.15% |
| 混合模式 | 10.00% | 10.00% | 10.00% | 10.00% | 10.00% | 10.00% | 10.00% | 10.00% | 10.00% | 10.00% |

真·随机使用混合模式式的均匀基础难度权重；线索玩法会先过滤噩梦词库。

## 首字母掩码

普通、困难和噩梦会按首字母长度随机掩码。设首字母串长度为 `L`：

| 模式 | L=4 | L=5 | L>=6 |
|---|---|---|---|
| 普通 | 30% 掩 1 个 | 20% 掩 1 个，10% 掩 2 个 | 15% 掩 1 个，10% 掩 2 个，5% 掩 3 个 |
| 困难 | 45% 掩 1 个 | 30% 掩 1 个，20% 掩 2 个 | 25% 掩 1 个，20% 掩 2 个，15% 掩 3 个 |
| 噩梦 | 55% 掩 1 个，15% 掩 2 个 | 35% 掩 1 个，35% 掩 2 个，10% 掩 3 个 | 25% 掩 1 个，30% 掩 2 个，25% 掩 3 个，10% 掩 4 个 |

其余概率为不掩码。掩码位置在首字母串内随机选择且不会重复。

本题总难度：

```text
首字母题总难度 = 词条基础难度 + 0.5 * 掩码字符数
线索题总难度 = 词条基础难度 + 0.5 * 破碎线索数
字谜整图难度 = 平均(词条基础难度 + 0.5 * 该词掩码字符数) + 格形加成
```

三角格和六边格字谜会给整图难度额外 +0.5。

## 提示

设答案中文名长度为 `n`。开局免费字词提示次数 `m` 满足：

```text
0 <= m <= floor(n / 2)
```

当 `n=1` 时只能为 0。当 `n>=2` 时，先按当前难度决定 `m=0` 的概率，再把剩余概率按指数衰减分给 `1..floor(n/2)`。

| 模式 | P(m=0) | 衰减参数 d | 字词提示冷却 |
|---|---:|---:|---:|
| 入门 | 50% | 0.78 | 30 秒 |
| 简单 | 55% | 0.55 | 45 秒 |
| 普通 | 60% | 0.38 | 60 秒 |
| 困难 | 65% | 0.25 | 75 秒 |
| 噩梦 | 75% | 0.16 | 90 秒 |
| 混合模式 | 60% | 0.45 | 60 秒 |

噩梦比困难更少给免费提示，并且提示冷却更长。提示词库按钮不受字词提示冷却影响，但仍会扣分；教程题除外。

每题初始 1000 分，每过 1 秒扣 1 分。提示扣分基于本题总难度：

```text
难度扣分系数 = 1.18 - 0.045 * 本题总难度
提示词库扣分 = max(90, round(210 * 难度扣分系数))
基础字词提示 = max(100, round(520 / 答案字数)) + 55 * (付费字词提示序号 - 1)
字词提示扣分 = max(65, round(基础字词提示 * 难度扣分系数))
```

字谜中的“提示”会随机揭开一个未确定格子，并记录类似 `A2` 的坐标；免费次数用完后按整图难度和提示次数扣分。字谜的“提示词库”会指出一个未解词的来源词库，并消耗本局词库提示次数。

线索模式第一次额外提示免费，之后从第三条线索开始扣分：

```text
线索提示扣分 = 模式基础值 + 18 * (本题总难度 - 1) + 70 * (付费线索提示序号 - 1)
```

线索基础值：入门 120、简单 170、普通 240、困难 330、混合模式 230。

## 计分与总积分

自由、限时和线索单题从 1000 分开始。字谜从 `400 * 要填词数` 开始。时间、付费提示、词库提示和揭晓答案会影响原始得分。

最终总积分按选词难度加权：

| 来源 | 权重 |
|---|---:|
| 入门 | 0.1 |
| 简单 | 0.2 |
| 普通 | 0.3 |
| 困难 | 0.4 |
| 噩梦 | 0.5 |
| 混合模式 | 0.25 |
| 真·随机 | 0.25 |

随机自由、随机限时和随机字谜按所选难度计入总积分。自定义记录不计入总积分、Rating、成就和常规统计。限时段位和线索段位的单题记录不计入常规统计；字谜段位按整图口径进入字谜统计、总积分和 Rating。

## Rating

Rating 衡量长期表现，显示三位小数，最大约 20。失败题 Rating 为 0。

单局常数：

```text
C = clamp(0.5 + 1.62 * 本题总难度 + 选词难度补正 + 玩法补正, 0.5, 20)
```

| 选词难度 | 补正 |
|---|---:|
| 入门 | -0.7 |
| 简单 | 0.0 |
| 普通 | 1.0 |
| 困难 | 3.3 |
| 噩梦 | 4.8 |
| 混合模式 | 1.0 |

| 玩法 | 补正 |
|---|---:|
| 自由 | 0.0 |
| 限时 | 0.25 |
| 线索 | 0.20 |
| 字谜 | 0.35 |
| 随机字谜 | 0.45 |

随机普通玩法不额外叠加玩法补正。表现质量 `Q` 综合原始得分、速度、提示和错误提交：

```text
期望用时 = 8 + 2.4 * 答案字数 + 1.6 * 本题总难度
Rating = clamp(C * ((Q - 0.55) / 0.45)^2, 0, 20)
```

字谜记录使用整局起始分和整图难度估算表现质量。同一局字谜按 record id 计为一条独立 Rating 记录。

总 Rating：

```text
作答Rating = 0.85 * B20均值 + 0.15 * R10均值
总Rating = clamp(作答Rating + 成就奖励, 0, 20)
```

同一个“模式 + 答案”只保留历史最高单局 Rating，避免反复刷同一词条。

## 记录、统计与成就

每条 record 会保存题目、答案、可接受答案、学科、玩法、选词难度、基础难度、总难度、首字母、掩码位置、线索内容、提交记录、提示次数、扣分明细、用时、原始得分和计入总积分。字谜 record 会额外保存网格、格形、词位置、交叉数、孤立词数和每个词的来源。

记录文件按月份和日期分层保存，例如：

```text
record/2026-05/2026-05-27/20260527_120426_xxxxxxxx.json
```

自定义记录会标记 `custom_mode` 和 `exclude_from_stats`。教程记录会标记 `tutorial_mode` 和 `exclude_from_stats`。自由/限时/线索段位记录也会排除常规统计，但仍用于段位展示和段位成就。

每日抽题轮转状态保存在 `profile/daily_terms.json`。账号设置保存在 `profile/player_settings.json`。段位进度保存在 `record/rank_progress.json`。

成就系统覆盖启动、首次答对、提示、掩码题、线索、随机、段位、字谜、累计时长和长期目标。设置页可以佩戴已解锁称号和段位标识；管理员后台可以查看全部用户数据，并以只读旁观模式进入玩家主页。
