# 词表生成指南

本文档规定 `words/` 下物理、数学词表的生成与审核标准。核心原则只有一句：词表里放“可以独立作为答案的专有名词或标准术语”，不要放“章节标题 + 泛化后缀”的拼接词。

## 先看入门词表

新增词表前，先参考这些文件的写法：

- `words/物理/入门模式：高中物理/high_school_mechanics_terms.csv`
- `words/物理/入门模式：高中物理/high_school_electromagnetism_terms.csv`
- `words/数学/入门模式：高中数学/high_school_geometry_terms.csv`
- `words/数学/入门模式：高中数学/high_school_sets_functions_terms.csv`

入门词表的特点是：

- 每行都是独立术语，例如“位移”“质心”“线段”“空间向量”。
- 不写“力学基本概念”“质数应用题型”“欧拉方程强变分”这种组合出来的描述。
- 英文名是机器可读的 snake_case，中文拼音无声调、连续小写。
- 难度不是“领域章节难度”，而是玩家根据首字母或线索能想到这个词的难度。

## CSV 字段

所有词表统一使用 UTF-8 BOM CSV，字段顺序固定为：

```text
编号,概念中文名,难度,中文首字母,中文首字母串长度,概念英文名,英文字符串长度,概念中文拼音,拼音字符串长度
```

示例：

```csv
编号,概念中文名,难度,中文首字母,中文首字母串长度,概念英文名,英文字符串长度,概念中文拼音,拼音字符串长度
1,位移,1,WY,2,displacement,12,weiyi,5
15,质心,2,ZX,2,center_of_mass,14,zhixin,6
```

字段规则：

- `编号`：从 1 开始连续递增，不跳号。
- `概念中文名`：标准中文术语，不加多余空格；除标准写法外，不使用括号解释。
- 若标准中文译名天然包含连字符，应保留连字符，例如“南部-戈德斯通玻色子”；游戏判题会允许玩家省略这个连字符。
- `难度`：1-12 的数字，放在“概念中文名”之后。
- `中文首字母`：中文名每个汉字拼音首字母，全部大写；保留标准缩写中的字母和数字，例如“格点QCD”可生成 `GDQCD`。
- 希腊字母不能忽略，应写成对应的大写希腊字母并计入长度，例如 `σ代数` 的首字母是 `ΣDS`，`π系λ系定理` 的首字母是 `ΠXΛXDL`，`βγ系统` 的首字母是 `ΒΓXT`。
- 中文名中含有人名、英文字母或希腊字母时，游戏会在题面标注对应提示；词表中仍按标准术语原样书写，不要为了回避提示而改名。
- `中文首字母串长度`：`中文首字母` 的字符数。
- `概念英文名`：英文标准名或可检索名，使用下划线连接；下划线计入长度。必要缩写可以保留大写，例如 `lattice_QCD`。
- `英文字符串长度`：英文名的字符数，包含下划线。
- `概念中文拼音`：中文名完整拼音，无声调，连续小写；缩写按其字母拼入或按现有生成脚本统一处理。
- `拼音字符串长度`：拼音字符串字符数。

## 什么算合格词条

合格词条必须满足至少一条：

- 是教材、讲义、论文、百科、索引或术语表里能独立出现的名词。
- 是定理、方程、模型、方法、算法、粒子、结构、空间、范畴、群、代数、场、张量、算子、近似、条件、变换、分布等标准术语。
- 是物理或数学共同体长期使用的中文译名。

不合格词条包括：

- 章节标题加模板词：`解析几何应用模型`、`组合典型题型`、`李群边界情况`。
- 主题词加泛化动作：`质数应用题型`、`欧拉方程证明思路`、`模空间局部模型`，除非它本身就是标准术语。
- 只描述题型或教学环节：`计算公式`、`分类讨论`、`证明思路`、`应用模型`。
- 中英混写但不是缩写：`Goldstone玻色子`、`Hybrid Monte Carlo`。
- 生硬直译或错误译名：例如应写“基灵矢量”，不要写“杀矢量”。

如果想生成一个方向的 100 个词，应该列 100 个真实术语，而不是拿 10 个主题乘以 10 个后缀。比如“初等数论”应包含“质数”“合数”“互质”“最大公因数”“欧几里得算法”“唯一分解定理”“费马小定理”等，而不是“质数基本概念”“质数应用题型”。

## 难度评估

难度先按模式定档，再按“玩家能否想到”细分。常用不等于简单，冷门不等于困难；核心性、可提示性和答案空间大小都要考虑。

推荐基础范围：

| 模式 | 基础难度范围 | 写法原则 |
|---|---:|---|
| 入门 | 1-3 | 高中核心概念，首字母和常识提示即可想到 |
| 简单 | 3-5 | 大学基础或竞赛常见概念，仍应是核心术语 |
| 普通 | 5-7 | 专业基础课常见术语，需要一定学科背景 |
| 困难 | 7-10 | 高年级、研究生或专门方向术语 |
| 噩梦 | 10-12 | 前沿、抽象、跨方向、高度专门化术语 |

内部细分时看这些因素：

- 核心性：`角动量` 很常用且核心，难度应低于同模式边缘词。
- 可想到性：`纯滚动` 常见但不如核心量直观，可略高。
- 边缘性：`体积模量`、`支点` 这类没有明确线索时较难联想到，难度可高于同模式常见词。
- 首字母歧义：首字母越短、越容易撞词，难度不一定低；首字母很长但结构明显时也可能较容易。
- 术语长度：长词通常更难，但不能只按长度打分。

## 掩码规则

词表 CSV 保存干净的 `中文首字母`，不要把 `*` 直接写入源词表。掩码应在出题时从干净首字母生成。

普通及以上模式加入掩码。设首字母长度为 `L`，星号数为 `m`：

| 模式 | L=4 | L=5 | L>=6 |
|---|---|---|---|
| 普通 | 30% 掉 1 个 | 20% 掉 1 个；10% 掉 2 个 | 15% 掉 1 个；10% 掉 2 个；5% 掉 3 个 |
| 困难 | 45% 掉 1 个 | 30% 掉 1 个；15% 掉 2 个 | 20% 掉 1 个；15% 掉 2 个；10% 掉 3 个 |
| 噩梦 | 55% 掉 1 个 | 35% 掉 1 个；20% 掉 2 个 | 25% 掉 1 个；20% 掉 2 个；15% 掉 3 个 |

规则：

- `L <= 3` 默认不掩码，除非玩法专门提高难度。
- 表中同一行的概率互斥抽取，不叠加。
- 随机位置不能重复；同一题中被掩掉的位置显示为 `*`。
- 本题总难度 = 基础难度 + `0.5 * m`。
- 总难度用于题目评分、Rating 和展示时，可以高于基础难度档位。

## 翻译与查证

中文名必须优先使用最常见中文译名。生成高端物理、数学词表时，必须先查证，不要直接保留英文人名或方法名。

保留英文的情况：

- 标准缩写：`QCD`、`CFT`、`BRST`、`HMC`、`LQG`、`AdS/CFT`。
- 公式或记号：`T0空间`、`Lp空间`、`n维流形`。
- 中文共同体本来就常用缩写组合：`格点QCD`。

需要翻译的情况：

| 不合格 | 合格 |
|---|---|
| Goldstone玻色子 | 戈德斯通玻色子 / 南部-戈德斯通玻色子 |
| Hybrid Monte Carlo | 混合蒙特卡洛 / 混合蒙特卡洛算法 |
| Killing vector | 基灵矢量 |
| Wilson loop | 威尔逊圈 |
| Haar measure | 哈尔测度 |
| Weyl group | 外尔群 |
| Chern class | 陈类 |
| Faddeev-Popov ghost | 法捷耶夫-波波夫鬼 |

查证优先级：

1. 中文教材、讲义、综述、百科词条、期刊论文和高校/研究所页面。
2. 若译名有多个，优先大陆学术语境最常见的说法，并保持全仓库一致。
3. 如果中文名需要保留缩写，应确认它是共同体标准写法，例如“格点QCD”。
4. 英文字段仍填写英文标准名，中文字段不要因此混入英文长词。

### 人名译名与别译

人名默认译名和可接受别译统一维护在 `words/人名/人名译名表.md`。新增含人名术语时先检查这张表：

- 词表里的中文名使用大陆学术语境最常见的默认译名。
- 同一人名存在多种音译时，把别译补进译名表，不要在不同 CSV 中来回切换默认写法。
- 别译只用于判题兼容；字谜模式会把玩家输入的别译折回词表默认译名。
- 译名表只写人名或人名整体，不要把“李群”“李代数”“戈德斯通玻色子”这类完整术语放进别译列，避免把不同术语误判为同一个人名。
- 若人名在固定术语里有通行短译，可以把短译作为默认写法，例如 `卡拉比-丘` 中的“丘”；完整姓名可作为别译。

查证示例来源：

- 基灵矢量场：<https://zh.wikipedia.org/wiki/%E5%9F%BA%E7%81%B5%E7%9F%A2%E9%87%8F%E5%9C%BA>
- 南部-戈德斯通定理：<https://zh.wikipedia.org/wiki/%E5%8D%97%E9%83%A8%E5%AE%9A%E7%90%86>
- 格点 QCD：<https://afsapply.ihep.ac.cn/cchelp/zh/experiments/LQCD/>
- 格点量子色动力学论文示例：<https://wulixb.iphy.ac.cn/article/doi/10.7498/aps.70.20210030>
- HMC/混合蒙特卡罗说明：<https://www.jos.org.cn/html/2014/7/4453.htm>

## 生成流程

1. 先确定模式、学科和子方向。
2. 为该子方向列出真实术语清单，不少于目标数量；先人工审一遍，删掉题型词、模板词和组合词。
3. 为每个术语查证中文标准译名和英文标准名。
4. 按 CSV 字段生成：编号、中文名、难度、首字母、长度、英文名、英文长度、拼音、拼音长度。
5. 在同一学科同一难度内去重；跨表重复时优先保留更合适的表。
6. 检查中文名中的英文 token，只允许标准缩写和记号。
7. 检查机械后缀：`基本概念`、`计算公式`、`应用模型`、`典型题型`、`分类讨论`、`对应方法`、`递推方法`、`边界情况`、`证明思路`、`计数策略` 等不能批量出现。
8. 运行测试。

## 验收命令

```powershell
python -m unittest tests.test_term_library_expansion -v
python -m unittest discover -v
Get-ChildItem -Recurse -Include *.py,*.pyw | ForEach-Object { python -m py_compile $_.FullName }
git diff --check
```

验收标准：

- 每张新词表至少 100 条，除非需求明确指定更少。
- 同一词表内没有重复中文名。
- 同一学科同一难度内没有重复中文名。
- 所有字段非空，长度字段与实际字符串一致。
- 中文名无未翻译英文长词。
- 中文名无“章节标题 + 泛化后缀”的批量拼接痕迹。
- 普通及以上模式的掩码由出题逻辑生成，不污染源 CSV。
