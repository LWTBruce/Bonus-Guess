# 词条解释段落写作规范

本文件用于指导每个词条的 Markdown 解释段落。玩家在结算页点击可接受答案后，会看到这一段解释，并配套查看一张 TeX 图。解释的目标不是写百科条目，而是在当前难度对应的知识基础上，帮助玩家确认“这个词是什么意思、为什么这样定义、它常用在哪里”。

## 写给谁：按难度调整深浅

不同难度的解释默认面对不同知识背景的玩家：

| 难度 | 默认读者基础 | 写法重点 |
| --- | --- | --- |
| 入门 | 高中知识 | 用熟悉类比引入，公式只保留核心关系，符号逐一说明。 |
| 简单 | 大学低年级 | 可以使用微积分、线性代数、基础力学和基础电磁学语言。 |
| 普通 | 大学高年级 | 可以使用抽象定义、泛函、张量、场论或测度语言，但仍要说明直观意义。 |
| 困难 | 研究生 | 可以使用专业模型、算符、流形、协变形式或实验装置细节，避免跳步堆术语。 |
| 噩梦 | 博士 | 可以涉及前沿理论、范畴化、量子场论或现代几何结构，但段落仍要清楚可读。 |

数学和物理都遵守同一分档逻辑：难度越高，允许使用的背景越深，但解释仍应保持平和、准确、简洁。

## 第一步：上网站逐词查找内容

批量撰写或润色词条时，第一步必须是逐词查资料，不能先套模板、再靠印象扩写。每个词条都应打开网络百科和可公开访问的基础资料，优先查百度百科、搜狗百科、维基百科，以及学科内常用的百科式页面或教材型页面；高难数学词条可同时参考 nLab、Encyclopedia of Mathematics、Scholarpedia、MathWorld 或大学讲义中的定义段落。

逐词查找时，要确认以下内容：

- 这个词最标准、最常见的定义是什么。
- 它的核心对象、限定条件和常见外延是什么。
- 它和相近概念的差别在哪里。
- 它在计算、实验、建模或证明中常怎样出现。
- 哪个公式、定义式或结构关系最能钉住这个概念。

不同资料说法不一致时，优先采用更接近标准教材、权威百科或常用学科定义的版本；拿不准时宁可写窄一些，围绕最公认的定义和公式说明，不要编造外延。含义相近的一组词也必须分别查资料，不能只查其中一个再把话术复制到其它词上。

## 第二步：整合资料并讲出来

查完资料后，再把多处资料中的共同信息消化成自己的解释。不要把百科原文直接复制进 JSON，也不要照搬百科的句式；应按本文件的长度、分段和读者难度要求，重新写成自然中文。写作目标是让玩家读完后知道“这个词是什么、由什么组成、在什么地方用、容易和什么混淆”，而不是看到一段百科摘要。

百科页面常常重叙历史、分类和应用，公式反而不充分。写入 `explanation_markdown` 时必须补上该词最能钉住概念的公式、定义式或结构关系，并解释公式里的符号。例如百科只说“特征值反映矩阵伸缩”，这里仍要补出 $A\mathbf v=\lambda\mathbf v$；百科只说“覆盖空间局部同胚”，这里仍要补出 $p^{-1}(U)=\bigsqcup_i V_i$ 和 $p|_{V_i}:V_i\to U$。

每个数学和物理词条都必须在 `source_links` 中附上至少两个可点击资料入口。每条链接使用 `{"label": "...", "title": "...", "url": "..."}` 结构；默认至少包含“百度百科”和“维基百科”，可再补 Wikipedia、MathWorld、nLab、Scholarpedia、HyperPhysics 等更合适的资料。链接不写进 `explanation_markdown` 正文，结算页弹窗会在解释下方单独显示为“百度百科：词条名”“维基百科：词条名”。

对含义相近的一组词，可以共享必要背景，但不能共享同一段话术。每个词都要写出自己的限定条件、公式位置或使用场景；若资料显示两个词只有细微差别，也要把差别自然写进定义或第二段说明中。

## 第三步：落到段落里

- 每个词条写约 200-300 个中文字符；物理词条可按内容自然分段，数学词条默认分为 2 段，必要时可用 3 段。不要把全部信息挤成一整块长段。
- 第一两句给出定义或核心图像，中间放入具体公式，最后说明意义、适用场景或常见用法。
- 需要包含有效 md 公式，以公式为基来进行讲解。例如 `$E_p=q\varphi$`、`$A\mathbf v=\lambda\mathbf v$`。
- 公式后要解释符号，不能只摆出公式。
- 解释重点放在概念本身：它指什么、为什么这样定义、包含哪些典型对象、不包含哪些容易混淆的对象，以及在实验、生活或工程中怎样被使用。可以提到做题中的识别或分析方法，但只作为一两句补充，不能把整段写成“题目中如何判断”的流程。
- 数学解释要直接进入定义和结构，不要先写空泛的否定铺垫。例如不要写“实谱三元组不是普通流形概念的简单改名，而是……”，应直接写“实谱三元组是把坐标环、微分形式和表示结构改写到非交换语境下的……”。玩家需要知道它是什么，不需要先读一段“它不是什么”的废话。
- 介绍内涵、外延和计算形式时，直接说内容本身，不要显式贴标签。不要反复使用“典型外延是……”“把它放到计算中，常见表达是……”这类讲义腔句式；可以直接写“它包括……”“常写成……”“在计算中……”。标签感越强，越像模板。
- 用中文用户熟悉的术语；除标准缩写外，不混用英文名称。
- 语言要尽量贴近中文母语者自然会用的说法，少用翻译腔、论文腔和英文句式倒装。优先用短句和常见动词，例如“是”“由……组成”“用来……”“可以写成……”，避免“对……进行刻画”“在……语境下实现……的表达”等堆叠表达。
- 语言要平和、朴素、简洁。不要使用夸张形容词、玩笑、宣传式表达或无意义铺垫。
- 不要把“章节标题 + 普通词语”写成概念解释。解释对象必须是一个真实术语。
- 不要为了显得高级而强行上升难度；入门词应服务于理解，噩梦词也要说清核心对象。

## TeX 图要求

- 每个词条配一张同名或可追踪的 `.tex` 图，推荐使用 TikZ 或 PGFPlots。
- 图应表达结构、几何关系、实验构型、变量依赖或推导关系，不做纯装饰。
- 图中文字短而清楚，尽量使用中文标注；公式标注保持 TeX 语法。
- 图中符号要与 Markdown 段落中的公式一致。
- 图应能独立编译或被统一模板包含，避免依赖本地截图。

## 写作心得

好的解释通常有三个层次：先把术语放进玩家已经知道的世界里，再给出它的数学或物理定义，最后指出这个定义为什么有用。你给出的两个示例都有这个特点：电势能先借重力势能建立直觉，再写出 $E_p=q\varphi$；切伦科夫探测器先说明辐射条件，再用辐射角公式连接实验测量。后续写作也应沿着这条路走。

另一个重要原则是“只讲这个词最核心的一件事”。一个词条解释不需要覆盖所有历史、所有变体和所有应用。尤其是高难词，最容易变成术语堆叠；写作时要优先选择一个主线公式或主线结构，把概念钉牢。

数学词条尤其要避免“同族词复制粘贴”。含义相近的词可以共享背景，但每个词必须写出自己的限定条件、结构角色或常用场景。例如霍普夫代数、准三角霍普夫代数和拟霍普夫代数都属于带余乘法的代数结构，但霍普夫代数要说清乘法与余乘法的兼容和 antipode，准三角霍普夫代数要突出 $R$ 矩阵给出的编织结构，拟霍普夫代数要突出结合律由 associator 调整。不要写“这个词的个性是……”，而要把差异自然放进定义、公式和用途里。

高难数学解释可以使用专业术语，但句子仍应像正常中文。优先用“某概念是……”“它由……组成”“常写成……”“这用于……”这样的直陈句；少用“不是……而是……”“其典型外延为……”“在计算层面可表达为……”等绕弯表达。除非真正需要排除误解，否则不要为了显得严谨而先写一段反面定义。

检查数学解释时，要把它当成给中文读者讲概念，而不是把英文教材句子翻译过来。能说“一个拓扑空间如果满足……，就叫……”，就不要写“……被用于刻画满足……性质的空间”；能说“这个矩阵把基向量之间的交换规则写出来”，就不要写“该矩阵实现了交换结构的范畴化编码”。术语可以专业，句子要顺口。

## 示例

### 入门 / 物理：电势能

电势能是电荷在电场中因位置不同而具有的能量，可以类比重力势能。选定参考点后，把电荷从参考点缓慢移到某点，外力所做的功会转化为电荷和电场共同具有的电势能；等价地说，电场力做功会使电势能减少。

若该点电势为 $\varphi$，电荷量为 $q$，则电势能为 $E_p=q\varphi$。这里的 $\varphi$ 由电场和参考点决定，$q$ 决定这个电荷在同一电势处对应的能量大小。静电场中电势能变化只与起止位置有关，与路径无关，这正是保守场的表现。对正电荷来说，沿电场线方向运动通常会使电势能降低；对负电荷则要注意电荷符号带来的相反趋势。

### 入门 / 数学：一元二次方程

一元二次方程是只含一个未知数，且未知数最高次数为二的方程，标准形式为 $ax^2+bx+c=0$，其中 $a\ne0$。它常用来描述抛物线与横轴的交点，也出现在运动、面积和最值问题中。

方程根的情况由判别式 $\Delta=b^2-4ac$ 决定：$\Delta>0$ 有两个不同实根，$\Delta=0$ 有一个重根，$\Delta<0$ 没有实根。求根公式 $x=(-b\pm\sqrt{\Delta})/(2a)$ 直接把系数 $a,b,c$ 转化为解，是高中代数中连接方程、函数图像和实际问题的基本工具。配方法可以解释公式来源，也能看出顶点横坐标为 $-b/(2a)$，这让方程求根和抛物线最值成为同一件事的两种表达。解应用题时，先确认未知量和取值范围，能避免得到代数上成立但实际无意义的根。

### 简单 / 物理：角动量

角动量描述物体相对某个参考点的转动状态。对质点而言，角动量定义为 $\mathbf L=\mathbf r\times\mathbf p$，其中 $\mathbf r$ 是从参考点指向质点的位置矢量，$\mathbf p=m\mathbf v$ 是动量。叉乘说明角动量不仅取决于速度大小，还取决于运动方向和力臂。

角动量随时间的变化由力矩决定：$d\mathbf L/dt=\boldsymbol\tau$，其中 $\boldsymbol\tau=\mathbf r\times\mathbf F$。若外力始终沿径向，例如行星在中心引力场中运动，则力矩为零，角动量守恒。这一守恒律解释了开普勒第二定律，也常用于碰撞、转动和散射问题。对绕定轴转动的刚体，还常写成 $L=I\omega$，其中 $I$ 是转动惯量，$\omega$ 是角速度，形式上对应平动中的动量关系。它强调的是“绕谁转”和“力臂多长”。

### 简单 / 数学：特征值

特征值描述一个线性变换在某些特殊方向上的伸缩比例。若非零向量 $\mathbf v$ 满足 $A\mathbf v=\lambda\mathbf v$，则 $\lambda$ 是矩阵 $A$ 的特征值，$\mathbf v$ 是对应的特征向量。这个式子表示经过 $A$ 作用后，$\mathbf v$ 的方向不变，只被放大、缩小或反向。

实际计算时，特征值通常由特征方程 $\det(A-\lambda I)=0$ 求出，其中 $I$ 是单位矩阵。特征值把矩阵的整体作用分解到若干方向上，因此在振动模式、递推关系、稳定性分析和量子力学算符中都很重要。若矩阵有足够多线性无关的特征向量，就可以对角化为 $A=PDP^{-1}$，复杂变换会化成沿各特征方向的独立伸缩。这样能把多变量耦合问题拆成较容易理解的单方向问题。

### 普通 / 物理：拉格朗日量

拉格朗日量是用广义坐标描述动力学的函数，常写作 $L(q,\dot q,t)=T-V$，其中 $q$ 是广义坐标，$\dot q$ 是广义速度，$T$ 为动能，$V$ 为势能。它不直接从受力出发，而是把系统的能量结构和约束条件放进同一个函数。

真实运动路径使作用量 $S=\int L\,dt$ 取驻值，由此得到欧拉-拉格朗日方程 $d(\partial L/\partial\dot q_i)/dt-\partial L/\partial q_i=0$。这个方程与牛顿定律等价，但在多自由度、非直角坐标和约束系统中更方便，也为哈密顿力学、场论和对称性分析提供统一入口。若某个坐标不显含在 $L$ 中，对应的广义动量会守恒，这也是诺特定理在基础力学中的直接影子。因此写出合适的 $L$ 往往比逐个分析受力更清楚。

### 普通 / 数学：勒贝格积分

勒贝格积分是测度论中的积分概念。与黎曼积分把定义域切成小区间不同，勒贝格积分先按函数取值分层，再累加各层在定义域中的测度，因此更适合处理不连续函数和极限过程。

对非负可测函数 $f$，可用简单函数 $s$ 从下方逼近，并定义 $\int f\,d\mu=\sup\int s\,d\mu$，其中 $s\le f$，$\mu$ 表示测度。这个定义使单调收敛定理和控制收敛定理成立得很自然，是现代分析、概率论和偏微分方程中处理“极限与积分交换”问题的基础语言。在概率论中，随机变量的期望也可写成 $\mathbb E X=\int X\,dP$，其中 $P$ 是概率测度。这说明“面积”和“平均值”可以由同一套测度语言表达。

### 困难 / 物理：切伦科夫探测器

切伦科夫探测器利用带电粒子在透明介质中运动速度超过该介质中光速时产生的切伦科夫辐射。辐射波前形成锥面，辐射角 $\theta$ 满足 $\cos\theta=c/(vn)$，其中 $v$ 是粒子速度，$n$ 是介质折射率。这个角度直接记录了粒子速度信息。

探测器通常由水、玻璃或气凝胶等辐射体，以及光电倍增管或光电探测阵列组成。测量辐射角可反推出速度；若动量已知，还可进一步区分粒子质量。切伦科夫光出现的阈值可写作 $v>c/n$，因此通过选择折射率能排除低于阈值的粒子。这个性质使它在高能物理、中微子实验和宇宙线探测中十分常用。

### 困难 / 数学：黎曼曲率张量

黎曼曲率张量刻画流形上协变导数沿不同方向交换时产生的差异。对向量场 $X,Y,Z$，它定义为 $R(X,Y)Z=\nabla_X\nabla_YZ-\nabla_Y\nabla_XZ-\nabla_{[X,Y]}Z$，其中 $\nabla$ 是联络给出的协变导数，$[X,Y]$ 是李括号。

如果曲率张量处处为零，向量沿小回路平行移动后不会发生净变化，局部几何接近欧氏空间；若不为零，平行移动会依赖路径。在坐标表示中，分量 $R^l{}_{ijk}$ 由克里斯托费尔符号及其导数给出，能进一步缩并成里奇张量 $R_{ij}$。它统一描述测地线偏离、截面曲率和里奇曲率，也是广义相对论中把时空几何写入引力方程的核心对象。直观上，它衡量的是空间本身怎样弯曲，而不只是坐标线怎样弯。

### 噩梦 / 物理：全息原理

全息原理认为，含引力体系中的物理自由度可以由边界上的较低维理论完整编码。它最初受到黑洞熵面积律的启发：$S=A/(4G\hbar)$，其中 $A$ 是黑洞视界面积，$G$ 是引力常数，$\hbar$ 是约化普朗克常数。这说明自由度数量更像随面积而非体积增长。

在反德西特空间/共形场论对应中，这一思想写成 $Z_{\mathrm{grav}}[\phi\to\phi_0]=Z_{\mathrm{CFT}}[\phi_0]$，其中 $\phi_0$ 是体场在边界上的取值。这里的“边界”不是普通容器外壳，而是能编码体内动力学的量子理论所在空间。它把高维引力理论与边界量子场论联系起来，是研究强耦合场论、黑洞信息和量子引力的重要框架，也提供了从几何语言理解纠缠结构的途径。

### 噩梦 / 数学：导范畴

导范畴是把链复形按拟同构等价后得到的范畴，用来系统保存同调信息。若 $\mathcal A$ 是阿贝尔范畴，导范畴 $D(\mathcal A)$ 中同调相同的复形会被视为等价对象，这使许多只依赖同调的构造可以在同一语言下处理。

一个核心关系是 $\mathrm{Hom}_{D(\mathcal A)}(X,Y[n])\cong \operatorname{Ext}^n(X,Y)$，其中 $Y[n]$ 表示平移后的复形，$\operatorname{Ext}^n$ 是扩张群。构造导范畴时，本质上是在链复形范畴中把拟同构形式地变成同构，因此它保留同调层面的信息，忽略不影响同调的表示细节。导范畴把 Ext、层上同调和三角结构放在统一框架中，是现代代数几何、表示论和同调代数的重要工具，也让许多原本分散的长正合列现象变成统一的三角结构。
