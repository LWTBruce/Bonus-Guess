# 线索重写风格说明

本文用于重写 `clues/` 中的线索。每个词条应当根据已有 `explanation_markdown` 或约 200 字左右的词条描述来改写；如果描述里有来源网页、百科页面或标准教材式介绍，应优先吸收其中的定义、用途、公式、典型条件和英文译名，再压缩为 5 条递进线索。

目标不是把解释原文缩短成摘要，而是让玩家能从宽到窄逐步判断这个专有名词是什么。线索应当像一层一层展开的信息，而不是互相重复的五句定义。

## 完整线索

每个词条写 5 条完整线索，顺序固定如下。

1. 第一条定方向和类型：写“这是一个什么方向的什么类型的词语”。例如物理量、公式、定律、近似、处理方法、数学对象、定理、判据、算法、构造等。
   句式可以是“这是一个电动力学方向的处理方法。”、“这是一个泛函分析中的重要定理。”、“这是一个概率论里的分布族。”
   第一条只给大方向和对象类型，不要提前写最有辨识度的特征，也不要写它处理哪几个具体对象、描述哪一种具体关系、满足哪一个典型条件或对应哪条典型公式。比如“这是高中力学中两个共点矢量相加的作图规则。”太清楚，应改成“这是高中力学中的一种作图规则。”；“两个共点矢量相加”这类辨识信息应移到第四条或后面的线索里。

2. 第二条写关联范围：说明它与什么问题、现象、模型、计算任务或理论结构有关。可以写它常出现在什么问题里、由什么条件引出、会带来什么现象、和哪些对象一起使用。
   这一条要把词条放回它所在的学科场景中，让玩家知道它和什么相连。

3. 第三条写公式或标准表达：给出一个与它有关、包含它、定义它或常用于描述它的公式、方程、记号、判据或典型关系。
   如果原描述里有公式，优先使用原公式。公式必须简短、可读，并保留必要符号说明。没有合适公式时，可以给标准记号、典型构造或判别条件。

4. 第四条写最明显的特征：给出这个词条本身最鲜明、最有辨识度的一面。
   这一条要具体，不写“它很重要”“它用于简化问题”这类空话。可以写它怎样组织对象、刻画什么结构、和相近概念相比有什么特别之处，或它最典型的成立条件。

5. 第五条写英语译名：直接给出英文译名。
   句式建议为“它的英文译名是 ...。”如果有常见缩写或标准记号，可以写在同一句里。

完整线索应当简明、清楚、有学科信息量。不要直接出现中文答案本身。除第五条英文译名外，不要用“中文名有几个字”“英文关键词接近”“难度为 X 级”“这个概念常会浮出来”“题目中的特定环节”等模板句。

## 语言风格

- 语言要贴近中文母语者的自然表达，像人在认真解释一个概念，而不是像提示词模板。
- 不写“核心是 XXX”“当 XXX 时可以锁定它”“它的内涵/外延是 XXX”“物理落点是 XXX”“指向这一类概念”等生硬句式。
- 线索只围绕词条本身展开，不谈使用注意事项、做题注意事项、猜题方法或区分技巧。例如描述“质点”时，不写“区分时看点状模型的具体角色”；应写点状近似、质量保留、空间尺寸被忽略等内容。
- 相近词条不能套同一组句式。越相似的词，越要主动写出各自不同的特点。例如同属“近似”的词条，可以分别突出尺度条件、保留量、被舍弃的项、适用对象或典型公式，而不是都写成“用于简化复杂问题”。
- 避免空泛形容。少写“重要、关键、典型、常见”单独撑起一句；这些词可以出现，但句子里必须有具体信息。
- 不为了让线索更像谜语而故意绕开学科事实。线索可以递进，但不能含混。

## 公式格式

- 完整线索和破碎线索中的公式都必须用 Markdown 数学格式写出。短公式统一写成 `$...$`，例如 `$F=ma$`、`$P(A|B)$`、`$1/|\mathbf r-\mathbf r'|$`。
- 破碎线索里的公式也要保留 `$...$`，不要写成裸公式或代码格式。正确写法是 `$P(A|B)$ 条件概率`，不是 `P(A|B) 条件概率` 或 `` `P(A|B)` 条件概率 ``。
- 公式线索可以是不完整表达，但仍要能读出它与词条的关系。例如 `$E_n=-13.6\,{\rm eV}/n^2$`、`$\nabla\cdot\mathbf B=0$`、`$\det A\ne0$`。
- 普通英文译名、缩写和专有名词不需要包成公式；只有数学/物理表达式、符号关系和标准记号使用 `$...$`。

线索模式的界面会按 Markdown 渲染线索；因此公式必须写成 Markdown 数学格式，才能和解释文段里的公式显示保持一致。

## 描述改写原则

- 先读词条已有描述，把信息分成：方向类型、关联范围、公式记号、明显特征、英文译名。
- 线索必须来自描述本身或对应来源页面中稳定、明确的信息，不要为了凑线索编造用途或公式。
- 改写线索时必须按词条逐个阅读、逐个改写，不要使用脚本批量生成或批量改写线索；脚本最多只能用于检查格式和统计问题。
- 每条线索只承担一个功能，避免同一条同时写定义、公式、用途和英文名。
- 第一条不要太窄，第四条不要太虚；第二条和第三条承担中间过渡。
- 如果描述中有多个公式，只选最能代表该词的一个；复杂公式可以截取关键部分。
- 如果词条是人名定理、方程或模型，第五条仍写英文名；第四条可以写它的典型结论、成立条件或结构特征。
- 如果词条没有明确公式，第三条可以写标准记号、判据、构造流程或最常见的数学/物理表达。

## 破碎线索

每个词条仍写 5 条破碎线索，与完整线索大体对应。

- 每条破碎线索是一组关键词块，不是完整句子。
- 只保留名词、形容词、关键动词、公式、标准记号和英文名。
- 第一条破碎线索也只写方向和类型，不写具体关系、对象组合、典型条件或最容易识别的特征。
- 可以保留数学公式、物理公式、符号、英文标准名，例如 `$\det A$`、`$\operatorname{Ker} f$`、`$P(A|B)$`、`$1/|\mathbf r-\mathbf r'|$`、`multipole expansion`。
- 不写“这是、通过、可以、能够、需要、用于、通常、因为、所以、这个、这种、它、收束、英文名、几级”等说明性碎片。
- 不直接出现中文答案本身。

## 示例：多极展开

原描述：

```text
多极展开把局域源在远处产生的势或场按角结构和距离幂次分层。总电荷、偶极、四极等低阶量依次给出越来越细的空间不对称信息。

远区核可展开为 $1/|\mathbf r-\mathbf r'|=1/r+(\mathbf r\cdot\mathbf r')/r^3+\cdots$，其中 $\mathbf r$ 是观察点，$\mathbf r'$ 是源点。条件是观察距离远大于源区尺寸。它让复杂源分布在远场中被少数多极矩近似，常用于静电势、辐射和散射。

展开阶数不是越高越好，而由精度和对称性决定；若低阶矩被抵消，下一阶才会成为远场或辐射的主导特征。它把源的几何信息转化为可逐阶截断的参数，适合远场和低频近似。这个近似依赖源区尺寸远小于观察距离或波长，若低阶矩被对称性抵消，高阶项就会成为主导。
```

完整线索：

1. 这是电动力学中的一种处理方法。
2. 它常用于计算静电势、辐射和散射等远场问题。
3. 观察距离远大于源区尺寸时，可写作 $1/|\mathbf r-\mathbf r'|=1/r+(\mathbf r\cdot\mathbf r')/r^3+\cdots$。
4. 它把局域源在远处产生的势或场按角结构和距离幂次分层。
5. 它的英文译名是 multipole expansion。

破碎线索：

1. 电动力学 处理方法
2. 静电势 辐射 散射 远场
3. $1/|\mathbf r-\mathbf r'|=1/r+(\mathbf r\cdot\mathbf r')/r^3+\cdots$
4. 局域源 势 场 角结构 距离幂次 分层
5. multipole expansion
