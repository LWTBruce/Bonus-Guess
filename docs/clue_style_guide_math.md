# 数学线索重写风格说明

## 完整线索

每个词条写 5 条完整线索，顺序要从宽到窄递进。

1. 第一条给具体对象、结构、场景或问题类型，不写“属于某方向”。
2. 第二条从另一个角度补充，例如运算、图像、映射、极限、分布、方程或代数结构。
3. 第三条给更具体的定义、公式、定理、判据、典型构造或解题入口。
4. 第四条基本锁定核心特征，但不直接出现中文答案本身。
5. 第五条用英文名、标准记号、常见公式或最强特征收束。

完整线索应当简明、清楚、有数学信息量。禁止使用“难度为 X 级”“中文名有几个字”“英文关键词接近”“它属于某方向”“这个概念常会浮出来”“题目中的特定环节”等模板句。

## 破碎线索

每个词条写 5 条破碎线索，与完整线索大体对应。

- 每条破碎线索是一组关键词块，不是完整句子。
- 只保留名词、形容词、关键动词、公式和标准记号。
- 可以保留数学公式、符号、英文标准名，例如 `det A`、`Ker f`、`P(A|B)`、`Cauchy integral formula`。
- 不写“通过、把、可以、能够、需要、用于、通常、因为、所以、这个、这种、它、收束、运用、定义语境、英文名、几级”等说明性碎片。
- 不直接出现中文答案本身。

示例：

- 完整线索：它讨论一个集合在运算下保持封闭并具有可逆性。  
  破碎线索：集合 运算 封闭 可逆
- 完整线索：判别时常检查单位元、逆元和结合律。  
  破碎线索：单位元 逆元 结合律
- 完整线索：常见记号是 `G`，英文名是 `group`。  
  破碎线索：G group
